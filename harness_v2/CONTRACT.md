# Canonical State Identity v2 / harness qualification only

This implementation extends the existing work. Temporal hypothesis remains UNTESTED. Old qualification packages remain invalid identity, without modification. No scientific v3 cohort or sensitivity labels are produced.

Identity bytes are UTF-8, fixed field order, decimal integers, newline terminated, locale independent. SHA-256 binds the entire exported logical/heuristic text. Variable IDs and DIMACS literals are one-based. Undefined assignment levels are -1; undefined reasons are empty. Assigned reasons use sorted full clause content. Logical identity contains assignments, decision levels, reasons, exact trail and decision boundaries, qhead, conflicts, decisions, native propagations, enqueue count, current level and trail length.

Heuristic identity uses var-ID-ordered exact hexadecimal floating point activity, saved polarity, decision eligibility; heap pop sequence from a deep copy with the original comparator (including native tie behavior); exact increments, RNG seed/options, decay, restart/reduction/simplification state; bounded queues in logical oldest-to-newest order with size and sum; active clause traversal, current literal order, stable sequential creation ID, clause activity/LBD/deletion eligibility; watcher traversal with stable clause IDs and blocker literals. IDs are deterministic clause creation ordinals, not CRefs, and are bound to full clause contents. No allocator offsets, raw refs, pointer values, capacities, object bytes or unused queue entries are serialized. Heap storage and inverse-index layout are not serialized. The harness supports the native default deterministic configuration, no assumptions and no external interrupts; source/binary/input hashes freeze that configuration. This is verification by native continuation, not a general deserializer for arbitrary solver configurations.

Qualification selection, fixed before collection: T8 and T10, first observer boundary in conflicts [200,299] with at least two legal actions. K_TEST=2, stable clause creation ID ascending, exact first two. The 200 boundary allows full LONG=128 history. Eligibility is existing active clause, zero true literals, exactly one undefined literal; binary clause either position, longer clause implied literal at index zero. One early enqueue with the original clause as reason. Observer boundary ordinal counts post-enqueue and search-loop-entry hooks from original CNF load. The ordinal and all semantic counters are frozen; replay never searches for alternate states.

Self-test runs A/B are independent baseline processes, export no actions/packages and continue to completion. Collector-only code freezes actions and the 128-entry logical temporal ring at the exact checkpoint then exits, before continuation outcomes. No per-conflict IO, JSON, allocation or candidate enumeration occurs in the temporal observer. Temporal records capture learned length, LBD, backjump, counter deltas and restart information from actual native hooks; features use the frozen v1.1 schema/formulas. At the checkpoint `conflicts_since_restart` is taken from the current state; ring records retain their individual epochs.

The replay binary is separately compiled with REPLAY and cannot compile the COLLECTOR candidate scan, action freeze or temporal package exporter. The runner validates artifact set, SHA-256 manifest, CNF, protocol/schema, canonical preimages, binary and runner identity before launching it. Native replay checks boundary/counters and both SHA-256 identities before any enqueue; action replay resolves only the requested stable clause ID and verifies source, full content, implied literal and unit/reason layout. No fallback is permitted. Proof checking uses the existing frozen drat-trim binary against original CNF. Route output is restricted to diagnostics, request, command, proof and metadata; package files are read only and their hashes are rechecked.
