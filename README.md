# SatFinding — concluded

This research direction is closed.

The project tested whether solver history could produce broadly reusable, exponential SAT search improvements. The experiments found reproducible but extremely narrow trajectory sensitivity, without a stable or predictive control rule. The evidence does not support a general history-driven optimization method.

The current-era evidence and its provenance remain archived under [`results/current_era_v1/`](results/current_era_v1/). Legacy experiments were retired because they are not reproducible under the current executable evidence contract; see [`LEGACY_TOMBSTONE_INDEX.md`](LEGACY_TOMBSTONE_INDEX.md).

Further work has moved to other directions. This repository is retained as the record of the completed investigation.
